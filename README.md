# 📚 스터디카페 예약 시스템 (Study Cafe Reservation System)

이 프로젝트는 Spring Boot와 MySQL(Docker)을 이용한 스터디카페 예약 시스템입니다.
아래 가이드를 순서대로 따라하시면 복잡한 DB 세팅 없이 프로젝트를 실행할 수 있습니다!
## Github 및 Docker 사용

### Step 0. 초기세팅
초기 세팅 완벽하게 해서 깃허브 main에 다 올려놨습니다. 
다들 개발 시작하시기 전에 딱 한 번만 아래 순서대로 세팅해 주시면 됩니다.

본인 컴퓨터에서 코드를 저장할 폴더를 하나 만들고,
그 폴더 안에서 터미널을 켜주세요.

- 1단계: 프로젝트 다운로드 (Clone)
터미널에 아래 명령어를 쳐서 저희 프로젝트를 통째로 다운받으시면 됩니다.
이거 터미널에 명령어 치세요 => git clone 우리 깃허브 주소
이거 터미널에 명령어 치세요 => git clone https://github.com/tysw2006/Study-A.git
안되면 당신 컴퓨터에 깃이 설치가 안된거임.

### Step 1. 나만의 작업 방(브랜치) 만들기

저 의외에 팀원들은 DBeaver 설치나 복잡한 SQL 실행이 필요 없습니다! 명령어 한 줄이면 DB 구조부터 테스트 데이터(좌석/룸)까지 자동으로 세팅됩니다.

1. **Terminal (터미널)**을 엽니다.
2. 터미널 창에서 본인이 작업하는 폴더 내 최상에서 아래 명령어를 치고 엔터를 누릅니다.
2. 터미널 창에서 본인이 작업하는 폴더 내에서 "studycafe" 폴더인 상태에서 아래 명령어를 치고 엔터를 누릅니다.
   docker-compose up -d
3. 설치가 주르륵 진행되고 Started 문구가 뜨면 완벽하게 끝난 것입니다.

### Step 4. spring Boot 서버 켜기
1.  초록색 재생 버튼(StudycafeApplication 또는 bootRun)을 눌러 스프링 서버를 켭니다.
2. 인터넷 브라우저를 열고 아래 주소로 접속하면 완성된 화면이 나타납니다!
   👉 접속 주소: http://localhost:8080

#### 테스트 계정 안내
서버 접속 후 아래 계정으로 로그인해서 바로 기능을 테스트해 볼 수 있습니다.
권한 : 일반 회원 (User)
아이디(이메일) : user@test.com
비밀번호 : 0987

#### 작업 종료 시 (참고사항)
작업이 모두 끝난 후, 컴퓨터가 느려지는 것을 방지하려면 Docker 실행을 꺼주시길 바랍니다.

### step 5. 코딩 다 하고 깃허브에 업로드하는 방법 (인텔리제이)
각자 브랜치에서 코드 작업을 다 끝내셨으면 깃허브에 올려주셔야 합니다.
1. 터미널 창을 열어주세요.
2. 폴더 내에 최상에서 아래 3줄을 순서대로 치면 깃허브에 업로드(Push) 완료입니다.
- 1단계: 내가 수정한 파일 전부 모으기
git add . (add 뒤에 띄어쓰기 한 칸 하고 마침표(.) 꼭 찍어야 해!)

- 2단계: 오늘 무슨 작업 했는지 메모(이름표) 붙이기
git commit -m "구글 로그인 기능 완성" (" " 쌍따옴표 안에 자기가 작업한 내용을 짧게 적어줘)

- 3단계: 깃허브로 쏘아 올리기 (가장 중요)
git push origin 본인브랜치이름


##  최신 업데이트 내역 (Auth-System 개편 및 보안 강화)

스터디카페 예약 시스템의 계정 보안성과 사용자 편의성을 높이기 위해 **이메일 인증 기반 회원가입 시스템**을 구축하고 전반적인 UI/UX 및 저장소 클린업을 진행했습니다.

---

### 1. 📧 이메일 인증 기반 회원가입 시스템
* **Google SMTP 연동**: Spring Boot Starter Mail을 활용한 비동기 메일 발송 파이프라인 구축
* **가독성 높은 HTML 템플릿**: 시각적 안정성과 스팸 필터 방지를 고려한 이메일 인증 템플릿 적용
* **보안 난수 생성**: `SecureRandom`을 활용하여 유추 불가능한 6자리 암호학적 난수 코드 발급

### 2. 🛡️ 계정 및 인증 보안 강화
* **유효시간 제한**: 발급된 인증번호는 발송 후 **3분(180초)** 동안만 유효
* **무차별 대입(Brute-Force) 방어**: 
  * 5회 오입력 초과 시 해당 인증번호 즉시 폐기 처리
  * 검증 실패 시 실시간 남은 시도 횟수 안내(`남은 시도: N회`)
* **1회성 인증 세션 관리**: 회원가입 완료 즉시 인증 세션을 메모리에서 파기하여 재사용 원천 차단
* **백엔드 2차 검증**: 프론트엔드 우회 요청을 방지하기 위해 가입 API 호출 시 서버단 인증 상태 재검증

### 3. 🎨 프론트엔드 UI/UX 개선 (`index.html`)
* **실시간 타이머 UI**: 인증번호 발송 시 3분 카운트다운(03:00) 타이머 동작
* **예외 상황 처리**: 5회 오입력 또는 시간 만료 시 타이머가 정지 및 제거되며, `[인증번호 재발급]` 버튼으로 자동 전환
* **폼 초기화 및 자동완성 제어**: 
  * 브라우저의 무분별한 비밀번호 자동완성 간섭 방지 (`autocomplete="new-password"`)
  * 화면 전환, 로그아웃, 회원 탈퇴 시 입력 폼을 초기화하여 이전 계정 정보 잔여 이슈 해결
* **부드러운 SPA 화면 전환**: DOM 참조 로직 안정화로 로그인/로그아웃 시 새로고침 없이 즉시 화면 전환 구현

### 4. 🗄️ 인프라 및 DB 안정화
* **한글 인코딩 및 타임존 보정**: Docker Compose 및 `application.yml`에 `UTF-8` 인코딩과 `Asia/Seoul` 타임존을 명시하여 글자 깨짐 및 시간 오차 방지

## ⚙️ 로컬 실행 및 환경 설정 안내 (For Contributors)

보안 강화를 위해 Google SMTP 계정 정보는 원격 저장소에 업로드되지 않습니다.  
로컬 환경에서 이메일 인증 기능을 테스트하려면 아래 설정을 완료해야 합니다.

### 1. `application.yml` 메일 설정
`studycafe/src/main/resources/application.yml`의 메일 설정 부분에 본인의 Google 계정 정보를 입력합니다:

```yaml
spring:
  mail:
    host: smtp.gmail.com
    port: 587
    username: "본인구글이메일@gmail.com"
    password: "구글 2단계 인증 16자리 앱 비밀번호"
