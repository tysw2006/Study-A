# 📚 스터디카페 예약 시스템 (Study Cafe Reservation System)

이 프로젝트는 Spring Boot와 MySQL(Docker)을 이용한 스터디카페 예약 시스템입니다.
아래 가이드를 순서대로 따라하시면 복잡한 DB 세팅 없이 프로젝트를 실행할 수 있습니다!
## Github 및 Docker 사용

### Step 0. 초기세팅
초기 세팅 완벽하게 해서 깃허브 main에 다 올려놨습니다. 
다들 개발 시작하시기 전에 딱 한 번만 아래 순서대로 세팅해 주시면 됩니다.

본인 컴퓨터에서 코드를 저장할 폴더를 하나 만들고,
그 폴더 안에서 터미널을 켜주세요.

- 1단계: 프로젝트 다운로드 (Clone)
터미널에 아래 명령어를 쳐서 저희 프로젝트를 통째로 다운받으시면 됩니다.
이거 터미널에 명령어 치세요 => git clone https://github.com/tysw2006/Study-A.git
안되면 당신 컴퓨터에 깃이 설치가 안된거임.

### Step 1. 나만의 작업 방(브랜치) 만들기

저희 프로젝트는 역할이 나뉘어 있어서 절대로 main 원본을 바로 건드리면 안됩니다.
각자 자기만의 작업 방(브랜치)을 만들어서 코드를 짠 다음 깃허브에 올려야 합니다.

1. IntelliJ를 켜고 **오른쪽 맨 위**에 보시면 main 이라고 적혀있습니다. 그걸 클릭하십시오.
2. 메뉴가 뜨면 맨 위에 있는 **+ New Branch (새 브랜치)**를 클릭하세요.
**이때 "브랜치 체크아웃"이랑 "기존 브랜치 덮어쓰기" 버튼이 나오실텐데 무조건 "브랜치 체크아웃" 눌러주세요**
3. 방 이름을 적으라고 나오면 아래처럼 자기 역할에 맞게 적고 "생성" 버튼을 눌러주세요.
4. 오른쪽 위에 main에서 자기가 만든 이름으로 바뀌었으면 성공입니다.

## Step 2. 개발 시작 전 컴퓨터에 아래 프로그램이 설치되어 있어야 합니다.

**Docker Desktop** (데이터베이스 자동 구동용)
- [👉 Docker Desktop 다운로드 링크](https://www.docker.com/products/docker-desktop) (윈도우/맥)
- 설치만 하시고 회원가입/로그인은 건너뛰셔도 됩니다.

Docker 켜기 (가장 중요 ⭐️)
1. 컴퓨터에서 **Docker Desktop** 프로그램을 실행합니다.
2. 화면 왼쪽 아래 고래 아이콘이 🟢 **초록색 (Engine running)**이 될 때까지 기다립니다. (이 창은 백그라운드에 계속 켜두세요)

### Step 3. 데이터베이스(DB) 자동 세팅하기
저 의외에 팀원들은 DBeaver 설치나 복잡한 SQL 실행이 필요 없습니다! 명령어 한 줄이면 DB 구조부터 테스트 데이터(좌석/룸)까지 자동으로 세팅됩니다.

1. **Terminal (터미널)**을 엽니다.
2. 터미널 창에서 본인이 작업하는 폴더 내에서 "studycafe" 폴더인 상태에서 아래 명령어를 치고 엔터를 누릅니다.
   docker-compose up -d
3. 설치가 주르륵 진행되고 Started 문구가 뜨면 완벽하게 끝난 것입니다.

### Step 4. spring Boot 서버 켜기
1.  초록색 재생 버튼(StudycafeApplication 또는 bootRun)을 눌러 스프링 서버를 켭니다.
2. 인터넷 브라우저를 열고 아래 주소로 접속하면 완성된 화면이 나타납니다!
   👉 접속 주소: http://localhost:8080

### step 5. 코딩 다 하고 깃허브에 업로드하는 방법 (인텔리제이)
각자 브랜치에서 코드 작업을 다 끝내셨으면 깃허브에 올려주셔야 합니다.
1. 터미널 창을 열어주세요.
2. 폴더 내에 최상에서 아래 3줄을 순서대로 치면 깃허브에 업로드(Push) 완료입니다.
- 1단계: 내가 수정한 파일 전부 모으기
git add . (add 뒤에 띄어쓰기 한 칸 하고 마침표(.) 꼭 찍어야 해!)

- 2단계: 오늘 무슨 작업 했는지 메모(이름표) 붙이기
git commit -m "구글 로그인 기능 완성" (" " 쌍따옴표 안에 자기가 작업한 내용을 짧게 적어줘)

- 3단계: 깃허브로 쏘아 올리기 (가장 중요)
git push origin 본인브랜치이름
