##  최신 업데이트 내역 (Auth-System 개편 및 보안 강화)

스터디카페 예약 시스템의 계정 보안성과 사용자 편의성을 높이기 위해 **이메일 인증 기반 회원가입 시스템**을 구축하고 전반적인 UI/UX 및 저장소 클린업을 진행했습니다.

---

### 1. 📧 이메일 인증 기반 회원가입 시스템
* **Google SMTP 연동**: Spring Boot Starter Mail을 활용한 비동기 메일 발송 파이프라인 구축
* **가독성 높은 HTML 템플릿**: 시각적 안정성과 스팸 필터 방지를 고려한 이메일 인증 템플릿 적용
* **보안 난수 생성**: `SecureRandom`을 활용하여 유추 불가능한 6자리 암호학적 난수 코드 발급

### 2. 🛡️ 계정 및 인증 보안 강화
* **유효시간 제한**: 발급된 인증번호는 발송 후 **3분(180초)** 동안만 유효
* **무차별 대입(Brute-Force) 방어**: 
  * 5회 오입력 초과 시 해당 인증번호 즉시 폐기 처리
  * 검증 실패 시 실시간 남은 시도 횟수 안내(`남은 시도: N회`)
* **1회성 인증 세션 관리**: 회원가입 완료 즉시 인증 세션을 메모리에서 파기하여 재사용 원천 차단
* **백엔드 2차 검증**: 프론트엔드 우회 요청을 방지하기 위해 가입 API 호출 시 서버단 인증 상태 재검증

### 3. 🎨 프론트엔드 UI/UX 개선 (`index.html`)
* **실시간 타이머 UI**: 인증번호 발송 시 3분 카운트다운(03:00) 타이머 동작
* **예외 상황 처리**: 5회 오입력 또는 시간 만료 시 타이머가 정지 및 제거되며, `[인증번호 재발급]` 버튼으로 자동 전환
* **폼 초기화 및 자동완성 제어**: 
  * 브라우저의 무분별한 비밀번호 자동완성 간섭 방지 (`autocomplete="new-password"`)
  * 화면 전환, 로그아웃, 회원 탈퇴 시 입력 폼을 초기화하여 이전 계정 정보 잔여 이슈 해결
* **부드러운 SPA 화면 전환**: DOM 참조 로직 안정화로 로그인/로그아웃 시 새로고침 없이 즉시 화면 전환 구현

### 4. 🗄️ 인프라 및 DB 안정화
* **한글 인코딩 및 타임존 보정**: Docker Compose 및 `application.yml`에 `UTF-8` 인코딩과 `Asia/Seoul` 타임존을 명시하여 글자 깨짐 및 시간 오차 방지

## ⚙️ 로컬 실행 및 환경 설정 안내 (For Contributors)

보안 강화를 위해 Google SMTP 계정 정보는 원격 저장소에 업로드되지 않습니다.  
로컬 환경에서 이메일 인증 기능을 테스트하려면 아래 설정을 완료해야 합니다.

### 1. `application.yml` 메일 설정
`studycafe/src/main/resources/application.yml`의 메일 설정 부분에 본인의 Google 계정 정보를 입력합니다:

```yaml
spring:
  mail:
    host: smtp.gmail.com
    port: 587
    username: "본인구글이메일@gmail.com"
    password: "구글 2단계 인증 16자리 앱 비밀번호"
